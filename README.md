# Kierz Majkowskich

Interaktywne drzewo genealogiczne rodu Majkowskich herbu Kościesza: od Majk-Tykiewek do Chodkowo Załogi, XV pokoleń od ok. 1690 roku.

Źródło: opracowanie „DLA PAMIĘCI POKOLEŃ Majkowskich. KIERZ rodziny od Majk-Tykiewek do Chodkowo Załogi” autorstwa Lecha Andrzeja Majkowskiego, przy współpracy braci Janusza Kazimierza i Tadeusza Wiktora Majkowskich (wersja z 12.01.2024).

## Zawartość

- `index.html` – strona (drzewo, karty osób, wyszukiwarka, „Historia rodu”)
- `data.js` – dane osób i opisy z opracowania
- `img/` – zdjęcia i skany z opracowania (nazwa pliku = numer strony oryginału)
- `vendor/d3.min.js` – biblioteka D3 v7.8.5 (licencja ISC, `vendor/d3-LICENSE.txt`)

Strona jest statyczna i działa na GitHub Pages bez budowania.
