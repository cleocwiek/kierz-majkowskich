# Kierz Majkowskich

Interaktywne drzewo genealogiczne rodu Majkowskich herbu Kościesza: od Majk-Tykiewek do Chodkowo Załogi, XV pokoleń od ok. 1690 roku.

## Źródła

- „DLA PAMIĘCI POKOLEŃ Majkowskich. KIERZ rodziny od Majk-Tykiewek do Chodkowo Załogi”: opracowanie Lecha Andrzeja Majkowskiego przy współpracy braci Janusza Kazimierza i Tadeusza Wiktora Majkowskich (wersja z 12.01.2024).
- „Suma lat… z biegu dni…”: Księga pamiątkowa dla o. Józefa Majkowskiego TJ, spisana przez siostrzenice, siostrzeńców i bratanków (Warszawa, 24.02.2014).
- Odnośniki do [ojozefmajkowski.pl](https://ojozefmajkowski.pl/) (pieśni, nagrania, wspomnienia zebrane przez wychowanków o. Józefa).

## Strony

- `index.html`: drzewo, karty osób (dane, zdjęcia z podpisami, opis z opracowania), wyszukiwarka i zakładka **Historie** z dłuższymi opowieściami (adresy `#rod`, `#zalogi`, `#boles`, `#jozef`, `#kakowscy`, `#poslowie`).
- `jozef.html`: podstrona o. Józefa Majkowskiego TJ: Księga pamiątkowa z fotografiami, rozdział z opracowania, odnośniki do pieśni i nagrań.

## Pliki

- `data.js`: osoby, opisy i historie z opracowania
- `jozef-data.js`: tekst Księgi pamiątkowej
- `img/`: zdjęcia z opracowania (nazwa = numer strony oryginału), `img/k/`: zdjęcia z Księgi
- `assets/`: wspólne style i skrypty
- `vendor/d3.min.js`: biblioteka D3 v7.8.5 (licencja ISC, `vendor/d3-LICENSE.txt`)

Strona jest statyczna i działa na GitHub Pages bez budowania.
